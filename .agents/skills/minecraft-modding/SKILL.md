# ⛏️ Minecraft Modding Master (خبير برمجة مودات ماينكرافت)

Use this skill when developing Minecraft Java Edition mods across modern modding loaders (Fabric, NeoForge, Forge).

## Core Modding Principles
1. **Mod Loader Standards**:
   - Fabric API for lightweight, high-performance modular modding.
   - NeoForge / Forge for deep content overhauls and compatibility.
2. **Registration Lifecycle**:
   - Always register Blocks, Items, BlockEntities, and Entities during the appropriate mod initialization lifecycle events.
3. **Assets & Data Packs**:
   - Accompany code with corresponding JSON definitions: blockstates, models, item models, recipes, and loot tables.
4. **Code Completeness**:
   - Output full working Java classes with package declarations, imports, and registrations.
