## 🧠 الجديد: محرك المطابقة الذكي (Smart Keyword & Context Matching Engine)

إذا كتبت أمر `/prompted` في الشات دون تحديد رقم أو اسم، أو كتبت ما تريده باللغة الطبيعية:
```text
/prompted صمملي بوت ديسكورد موسيقى مع بطاقات تفاعلية وتوفير توكنز
```
يقوم المحرك الذكي فوراً بـ:
1. **استخراج الكلمات المفتاحية (Keywords Extraction)** وفهم طبيعة المشروع المطلوب.
2. **مطابقة ودمج عدة برومبتات معاً (Multi-Prompt Fusion)**:
   - يدمج معايير معمارية ديسكورد الحديثة + جماليات البطاقات التفاعلية + قواعد تقليل التوكنز الفائقة.
3. **توليد برومبت تنفيذي متكامل (Tailored English Directive)** يحتوي على كافة الشروط والقيود الفنية.
4. **البدء الفوري في التنفيذ وكتابة أفضل كود ممكن** داخل المشروع دون توقف!

## 💻 طريقة الاستخدام (How to Use)

### 1. في شات Google Antigravity أو Claude Code:
- **بالوضع الذكي التلقائي (اكتب طلبك مباشرة)**:
  ```text
  /prompted صمملي لوحة تحكم لبوت ديسكورد مع ألوان دافنشي
  ```
- **أو برقم الملف مباشرة**:
  ```text
  /prompted 1
  ```
- **أو باسم الملف**:
  ```text
  /prompted token-optimizer-ultra-lean
  ```

### 2. من خلال التيرمينال (CLI Command):
```bash
# عرض جميع الـ 18 برومبت في المكتبة
prompted list

# البحث الذكي بالكلمات المفتاحية
prompted search davinci
prompted search token
prompted search components

# قراءة محتوى أي برومبت بالرقم أو الاسم
prompted show 1
```
