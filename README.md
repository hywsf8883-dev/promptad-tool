## 📖 ما هي أداة برومتد (What is Prompted)?

**برومتد (Prompted)** هي أداة وإضافة بيئة عمل متطورة مصممة لمطوري الذكاء الاصطناعي على **Google Antigravity** و **Claude Code**.

تتيح لك حفظ وإدارة برومبتاتك الضخمة والقوية داخل مجلد `prompts/` (مثل برومبتات ديسكورد الشاملة، مودات ماينكرافت، الداشبورد، وأدوات التشخيص البرمجي)، ثم استدعاؤها بلمسة واحدة:
1. في شات Antigravity أو Claude Code، تكتب فقط:
   ```bash
   /prompted
   ```
2. يعرض لك المساعد قائمة بجميع البرومات المتاحة في مكتبتك مع أحجامها، عناوينها، وأوصافها.
3. بمجرد اختيار برومبت، يقوم المساعد تلقائياً بـ:
   - **قراءة الملف بالكامل وفهمه**.
   - **تلخيص الهدف** في نقاط موجزة ودقيقة.
   - **تحسينه وفق أعلى معايير الـ Prompt Engineering** (تحديد الدور القيادي، فرض معايير الكود الكامل بدون نواقص، استراتيجيات الاختبار، معالجة الأخطاء).
   - **صياغته وترجمته إلى إنجليزية برمجية فائقة الدقة** (لتحقيق أعلى مستوى استدلال منطقي وجودة كود).
   - **إرساله لنفسه والبدء في تنفيذه فوراً** داخل المشروع دون الحاجة لنسخ أو لصق أي شيء!

## 🧩 المهارات المدمجة لـ Antigravity (Antigravity Skills)

بالإضافة لأمر `/prompted` الشامل، تم تزويد المشروع بمهارات مخصصة جاهزة داخل `.agents/skills/`:

## 💻 طريقة الاستخدام (How to Use)

### 1. في Google Antigravity:
```text
/prompted
```
أو بالاسم مباشرة:
```text
/prompted discord-mega-expert-ultimate-prompt
```
أو بالرقم:
```text
/prompted 1
```

### 2. في Claude Code:
```text
/prompted
```
أو:
```text
/prompted 10
```

### 3. من خلال التيرمينال (CLI):
```bash
# عرض جميع البرومات المتوفرة
node bin/prompted.js list

# قراءة محتوى أي برومبت بالرقم أو الاسم
node bin/prompted.js show 1

# إضافة قالب برومبت جديد
node bin/prompted.js add my-feature-prompt
```

## ➕ كيفية إضافة برومبتاتك الخاصة (Add Your Own Prompts)

ضع أي ملف `.md` داخل مجلد `prompts/`:
```markdown
# عنوان البرومبت الخاص بك

وصف: سطر أو سطرين يشرحان وظيفة هذا البرومبت.

## المطلوب
- اكتب هنا أفكارك بالعربية أو بالعامية أو بأي لغة...
```
بمجرد حفظ الملف، سيظهر تلقائياً في قائمة `/prompted`!

## 📤 كيفية رفع المشروع على GitHub (Push to GitHub)

1. أنشئ مستودعاً جديداً فارغاً على GitHub باسم `prompted`.
2. داخل مجلد المشروع، نفذ الأوامر التالية:

```bash
git init
git add .
git commit -m "feat: initial commit for prompted with master prompts library"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/prompted.git
git push -u origin main
```
*(استبدل `YOUR_USERNAME` باسم المستخدم الخاص بك على GitHub).*
