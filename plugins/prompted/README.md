# Prompted Plugin for Antigravity

This plugin provides the `/prompted` command and skill for Google Antigravity.

## Features
- **Prompt Discovery**: Scans local `./prompts/` and global `~/.prompted/prompts/`.
- **Interactive Menu**: Shows all available prompt files with names, titles, and descriptions.
- **Smart Optimization**: Summarizes, improves, and translates prompts to high-performance English.
- **Self-Execution**: Automatically adopts the optimized prompt and begins executing it immediately in your project.

## Installation
Run `.\install.ps1` (Windows) or `./install.sh` (macOS/Linux) from the root repository.
