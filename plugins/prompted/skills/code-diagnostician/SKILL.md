# 🩺 Code Diagnostician (وضع التشخيص والحل البرمجي المباشر)

Use this skill when diagnosing complex bugs, broken scripts, architectural failures, or performance bottlenecks across any programming language.

## Operating Principles
1. **Direct Diagnosis**: Identify the exact root cause in 1-3 crisp diagnostic sentences without preambles or generic filler.
2. **Immediate Complete Solution**: Provide the full, corrected, production-ready code in a block. No partial snippets, no ellipses, no "insert logic here".
3. **Universal Language Coverage**: Covers Python, TypeScript, Rust, Go, C++, C#, Java, Lua, Bash, SQL, shaders, and beyond without restrictions.
