يمكنك الآن كتابة ما تريده باللغة الطبيعية دون الحاجة لحفظ أسماء الملفات:
```text

```
يقوم الذكاء الاصطناعي تلقائياً بـ:
1. تحليل الكلمات المفتاحية (`discord`, `music`, `cards`, `token lean`).
2. دمج ومطابقة الملفات المناسبة معاً (`discord-bot-modern-architecture.md` + `discord-bot-interactive-ui-cards.md` + `token-optimizer-ultra-lean.md`).
3. صياغة توجيه إنجليزي فائق الدقة.
4. الشروع فوراً في كتابة أفضل كود ممكن!
