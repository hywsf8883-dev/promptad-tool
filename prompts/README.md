## 💡 كيف تستخدم أي برومبت منها؟

في محادثة **Google Antigravity** أو **Claude Code**:
```text
/prompted
```
أو حدد اسم البرومبت مباشرة:
```text
/prompted discord-mega-expert-ultimate-prompt
```
أو برقم الملف:
```text
/prompted 9
```

يقوم الذكاء الاصطناعي فوراً بـ:
1. قراءة الملف وفهمه.
2. تلخيص أهدافه التقنية.
3. تحسينه وصياغته هندسياً باللغة الإنجليزية لأعلى أداء استدلالي.
4. إرساله لنفسه وتولي الدور والبدء في تنفيذ مهام المشروع مباشرة!
